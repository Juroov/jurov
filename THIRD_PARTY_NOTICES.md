# React Bits

This portfolio includes components adapted from [React Bits](https://github.com/DavidHDev/react-bits) by David Haz, retrieved October 25, 2026.

Components: BlurText, RotatingText, ShinyText, SpotlightCard, Magnet, StarBorder, TiltedCard, CountUp, and AnimatedContent.

The original license is included at [app/components/react-bits/LICENSE.react-bits.md](app/components/react-bits/LICENSE.react-bits.md). Components are used as part of this portfolio website.

Local changes: use the installed Framer Motion runtime; use an inline span for BlurText so it can sit inside semantic headings; adapt AnimatedContent to a single viewport reveal without GSAP; move animation settings updates into effects for React 19 compatibility; optimize TiltedCard images with Next.js Image; respect the site's crimson and ivory palette.
